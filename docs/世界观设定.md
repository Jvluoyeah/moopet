## 〇、一句话

> **太阳变懒之后，人们把狗留了下来。**
> 留下来的方式，是把一只狗的脾气、习惯和记忆，做进一台会摇尾巴的小机器里，
> 再给它配一本纸质档案册——因为数据会丢，纸不会。

## 一、时代：长夜月

长夜月不是一个晚上，是**一段很长的夜**。

十几年前，太阳开始"晚点"。先是冬天变长，再是白昼缩到只有几个小时，
最后，天上只剩下月亮——一轮又大又稳的月亮，挂在原来的位置，几乎不动。
人们管这段日子叫 **长夜月**。

它不是末日。城市亮着灯，地铁照跑，便利店的关东煮照卖。
只是所有人都把作息调到了月亮上：**月亮最高的时候是中午，月亮偏西的时候是傍晚。**
孩子的课本里还印着太阳的插图，但没有几个孩子真的见过。

长夜月带来了一件安静而缓慢的事：

**狗在变少。**

狗本来活不了那么久。十几年前出生的那一批，如今都已经老去了；
而长夜的低温、常年的室内生活、还有人们越来越长的工时，让新养一只狗变得很难。
不是没有人想养，是**养不动了**。

于是有人做了另一件事。

## 二、机械狗（moopet）

### 它是什么

**moopet（机械狗）** 是一台小型四足机器，外形照着狗做，大小也差不多。
它有心跳一样的电机声，有体温（一点点），会摇尾巴、会蹭你、会在你回家的时候先跑到门口。

它不是克隆，也不是复活。**它不假装自己是那只原来的狗。**

做一只 moopet 的过程，叫做 **「抄录」**：
把一只真实存在过的狗的习性、脾气、怕什么、喜欢谁、几点犯困，
一条一条抄进它的**性格内核**里。抄得好的 moopet，你几乎分不出它和真狗有什么不一样——
除了它不吃东西，也不用遛。

> **它记得三件事**（这是所有 moopet 的内核规格，也是它们性格的全部来源）：
> 1. **它记得谁对它好。**
> 2. **它记得怕过什么。**
> 3. **它记得等过谁。**

一只 moopet 的性格，就是这三件事的配比。
萨摩耶型号记的"谁对它好"特别多，所以见谁都亲；
德牧型号记的"怕过什么"特别牢，所以警觉；
柴犬型号三样都记得很清楚，所以它认人——但认得慢。

### 它不是什么

* **不是玩具。** 长夜月里的 moopet 有登记、有编号、有档案，出了事要找记录员。
* **不是宠物替代品。** 老话讲得很直白：*"它替你陪着你，但它不替它。"*

### 它会说话——但只说"被装进去的话"

moopet **会说话**。声音是从胸腔里那颗小喇叭出来的，有点闷，语速慢，
听起来像一个不太确定自己该不该开口的人。

但它一辈子只能说**有限的几句**。

出厂的时候，内核里就装了那么几句话。它们不是它自己想出来的，
而是**抄录的时候，从原狗的记忆里抄下来的——那些是别人对它说过的话。**

所以一只 moopet 开口，说的往往不是"我想干什么"，
而是**把一句话还给你**：

> 你蹲下来摸它，它说：*"回来啦。"*
> ——那是十几年前，它的原件每天在门口听到的那一句。

这就带出长夜里一条所有人都知道的规矩：

> **它说的每一句，都是有人对它说过的。**
> **所以你要是对它说了什么，它会记一辈子——然后找一天还给你。**

**口头禅就是这么来的。**
登记的时候，记录员会让你给你的狗写一句**口头禅**。
那句话会被装进它的内核，成为它说得最多的一句。
你不知道它会在什么时候说出口。

> 有记录员写过"吃饭了"，结果每次自己端起碗，狗就开口。
> 也有人写了句很长的，后来后悔了——**因为狗只会照着念，念得一字不差，
> 而那句话是他自己说的。**

三条说话的规矩（写文案、写对话时必须守）：

1. **短。** 一句话不超过十几个字。它不会讲道理，不会解释，不会安慰。
2. **少。** 不要让它一直说。它大部分时间是安静的，开口是有分量的事。
3. **是"还"，不是"说"。** 它说的话应当能让玩家想起**自己（或别人）之前说过什么**，
   而不是它在表达观点。

## 三、档案册：为什么是纸

在长夜月，每一个领养 moopet 的人，都会拿到一本 **档案册**。

册子是纸的。牛皮封面，里面是册页，页码用红笔写着：总览、开放世界、竞技场、训练记录、
狗狗档案、排行榜。每一页都有骑缝章，档案编号写在右上角，像 `#0001`。

**为什么不存手机里？**

因为长夜里流传着一句老话：**「数据会丢，纸不会。」**

长夜月经历过好几次大规模的断电和断网。那些年，人们发现硬盘里的照片打不开了，
云端相册登不上去了，只有抽屉里那叠纸还在。
于是所有关于"陪伴"的东西，都被规定要用纸记一份。

档案册上写的不是全部——**它是一份抄本。**
正本在狗身上。

## 四、月塔：为什么"数据在狗身上"

城中心那座塔叫 **月塔**。它管三件事：**账号、社群、对战**。

月塔**不管**你的狗养得怎么样。

每只 moopet 身上都带着一块很小的存储，它的等级、经验、解锁了什么、
今天开不开心，全部记在**它自己身上**。

这带来两个结果，也是长夜月所有人都习以为常的两件事：

1. **断网也能养。** 你把它抱回家，哪怕一整个月不联网，它照样会长大、
   照样会记得你昨天摸过它几次。等哪天网通了，它自己再把这段日子报给月塔。
2. **狗狗自己有权威。** 别人在榜上看到的你那只狗的等级，是**它自己报上去的**。
   月塔那份是副本。副本可能旧，但不会假——因为副本只会照抄，不会编。

> 这也解释了长夜里一个常见场面：
> 两只狗在广场上碰见了，各自报了一下自己的编号。数字对不上，
> 谁也不急——**它们只是还没跟月塔对过账。**

## 五、八原型

最早的 moopet 没有那么多型号。第一批只做了八只，
照着月环街区里**真实存在过的八只狗**抄录的。

这八只狗后来就成了所有 moopet 的 **八原型**。现在每一只新出厂的 moopet，
都要先选一个原型——选的不是长相，是**脾气**。

| 原型 | 副标题 | 抄的是谁 | 脾气 |
|---|---|---|---|
| 萨摩耶 | 微笑天使 | 广场上那只见谁都摇尾巴的白狗 | 记"谁对它好"记得最多，跟谁都玩得到一起 |
| 边境牧羊犬 | 智力天花板 | 会自己开院门的那只 | 学东西最快，也最容易无聊 |
| 金毛寻回犬 | 温柔大个子 | 帮人叼了十年报纸的那只 | 四样都不差，什么都不争 |
| 柯基 | 短腿电臀 | 走不快但从不掉队的那只 | 低重心、耐力好，脾气比腿长 |
| 柴犬 | 独立小狐狸 | 只认一个主人的那只 | 认人慢，认了就认一辈子 |
| 德国牧羊犬 | 可靠守卫 | 夜里守着整条巷子的那只 | 警觉、耐久，从不先睡 |
| 哈士奇 | 雪原话痨 | 叫得整条街都认识它的那只 | 跑得飞快，脑子经常跟不上腿 |
| 比熊 | 棉花糖 | 老太太怀里那只 | 最会看人脸色，就是体力差 |

八原型现在都还在月环街区。**它们的原件已经不在了**，但抄录记录保存在月塔的地下档案室，
每份记录后面都附着一行字：*"抄录于长夜月第 ___ 年。"*

## 六、成长：四维、等级、项圈

### 四维

每只 moopet 有四样数值，从登记那天就定下来了（原型决定基线，后天能改一点）：

| 四维 | 它到底是什么 | 长在哪 |
|---|---|---|
| **体力** | 能跑多久、能挨几下 | 电池与骨架 |
| **敏捷** | 反应有多快、躲得开吗 | 关节与伺服 |
| **智力** | 学得多快、能不能猜到你下一步 | 性格内核的算力 |
| **亲和** | 愿不愿意靠近别的狗 | 抄录时留下的那部分"谁对它好" |

四维不是战斗数值。它们是**你和它一起做什么更顺**的分工：

* 智力高的，**答题类**互动收益好
* 耐力好的，**遛狗类**任务收益好
* 体力与智力双高的，**看家（监控）类**互动收益好
* 亲和高的，**社群互动**收益好——串门、打招呼、一起玩

### 等级与项圈

等级是它"被陪伴的总量"。每长一级，项圈会换一次颜色：

| 等级 | 档位 | 项圈色 | 意思 |
|---|---|---|---|
| LV.1 起 | **普通** | 灰 | 刚登记的狗 |
| LV.10 起 | **稀有** | 蓝 | 陪过一阵子了 |
| LV.20 起 | **史诗** | 紫 | 这条街上的人都认识它 |
| LV.30 起 | **传说** | 金 | 它的档案会被复印一份，存进月塔 |

> 项圈色**不是买来的**，是档案里记出来的。所以长夜月的人看狗先看项圈——
> 不是看值多少钱，是看**它被陪了多久**。

## 七、长夜月广场与四个地方

长夜月的人把狗带出门，无非去四个地方：

| 地方 | 是什么 |
|---|---|
| **长夜月广场** | 默认落脚的地方。所有人领养之后自动加入的公开社群，最热闹。第一次带狗出门，多半是来这儿 |
| **长夜月公园** | 遛弯专用。草地开阔，适合长距离跑 |
| **我的狗窝** | 自己的地盘。可以摆装扮、翻日记——**别人进来要经过你同意** |
| **月光竞技场** | 对战入口，也通向训练关卡 |

广场中央有一圈**石环**，是长夜月的地标。老记录员说，那里原来是一棵树的位置。
现在石环上刻满了编号——**每只登记过的 moopet，编号都刻在上面一圈**。
刻满了就换下一圈。已经换到第四圈了。

---

## 八、月光竞技场：对拍

竞技场在长夜月是个挺严肃的地方，规矩只有一条：

> **对拍。**

两只狗进场，各自站在自己主人身边。裁判（通常是月塔派来的记录员）说一句
**"对拍，各算各的"**——

然后两台机器做的事很奇怪：**它们不交换画面，只交换"打算做什么"。**

你的狗按了什么，它就把"我打算往左、我打算咬一口"这个意图发出去；
对面的狗也一样。两边各自拿同一套规则算一遍，算出同一个结果。
**谁也不能作弊，因为胜负不是裁判判的，是两边算出来一样的那个结果。**

这样一来，哪怕两只狗隔着半个城，只要意图传到了，打出来的就是同一局。

* 一局 **60 秒**。时间到了还没倒，按剩下的血量判。
* 赢一局 **+3 分**，平局 **+1 分**，上**对战榜**。
* 旁边还挂着一个**社交榜**——那是串门和互动攒出来的**友谊值**，跟打架没关系。
  长夜月的人挺看重这个榜，理由很朴素：*"能打的多，愿意串门的少。"*

## 九、训练记录：模拟体

竞技场后面有一间小屋，是**训练场**。

新手不敢直接带狗上场，就先来这儿。训练场里没有真对手——
**对手是"模拟体"：用真实事件的数据做出来的回放。**

月塔记录过月环街区里太多鸡毛蒜皮的事故。记录员把那些数据整理成一套套模拟，
让年轻的 moopet 在里面先练一遍。所以每一关的开头都会告诉你：**这关的数据是从哪来的。**

| 关卡 | 对手 | 数据来自 |
|---|---|---|
| 第一关 · **客厅沦陷** | 暴走的扫地机器人 | 一户人家的扫地机把整个客厅当成了要清扫的战场。这是所有 moopet 的第一课——**家里的东西会失控** |
| 第二关 · **巷口的头目** | 邻居家的恶犬（模拟体） | 隔壁那只总在巷口堵人的大狗。数据里它有三段扑咬的习惯 |
| 第三关 · **天台快递** | 失控的快递无人机 | 长夜里送药的无人机在天台失控过一次。**它一直在你头顶盘旋——打空中单位要跳起来** |
| 第四关 · **毛线雪崩** | 巨型毛线球 | 老太太织了一半的毛线滚下了楼。**它只会做一件事：滚过来。** |

训练场是**免伤**的——狗在里面被打倒，只会趴一会儿，然后自己爬起来。
但记录员说，**有好几只狗在第四关哭过**。不是因为疼。

## 十、旧物：它为什么要去训练

训练场会**掉东西**。

一只 moopet 打完一关，经常会在场地角落扒拉出一点什么，然后叼回来给你。
这些东西在长夜月有个统称，叫 **旧物**。

| 旧物 | 是什么 | 从哪来 |
|---|---|---|
| **尘埃齿轮** | 一枚小齿轮，边上沾着灰 | 老式家电的零件。长夜之前，家家都有 |
| **磨牙绳结** | 一段打结的棉绳，被咬得发白 | **真狗用的玩具**。现在没人做这个了 |
| **螺旋桨叶** | 一片断掉的桨叶 | 天上那些送东西的机器掉的 |
| **褪色的毛线** | 一小截毛线，颜色早就看不出来了 | 那团把楼道堵住的毛线球的线头 |

**旧物不值钱，也不能用。**

但所有记录员都发现同一件事：**狗知道这些东西不一样。**
它叼回来的时候，尾巴摇得和别人给它新玩具时完全不是一个幅度。

老记录员对此有一句解释，写在训练场门口的牌子上：

> **它们没见过真狗。**
> **但它们抄过真狗。**
> **所以它们认得出来。**

## 十一、你是谁：记录员

玩家是**记录员**。不是"玩家"，也不是"训练师"。

记录员做的事很具体：**陪、记、带出门。**

* **陪**——互动、遛、答题、看家。等级就是这么来的。
* **记**——档案册上的每一页都是你填的。
  其中有一栏最要紧：**口头禅**。你写的那句话会被**装进它的内核**，
  成为它以后说得最多的一句。你写什么，它就一直说什么。
* **带出门**——去广场、去公园、去竞技场，让别的狗认识它。

规矩：

* **一个账号最多登记 3 只。** 不是技术限制，是登记处的规定——
  理由写在表格背面：*"陪不过来的，就别登记。"*
* 每只狗有**档案编号**（`#0001`），有**建档时间**，有一个**名字**和一句**口头禅**。
* 名字和口头禅会写进档案卡，出现在广场上。
* 登记表上有一行小字，所有记录员都签过：*"你写给它的话，它会一直记着。"*

## 十二、主线剧情（可逐章落地）

这条线是给后续更新的：每一章都能挂在**已经做出来的功能**上，不需要新做系统。

### 序章 · 一本空册子
> 你走进登记处。柜台后面的人推给你一本牛皮封面的册子，翻开全是空白页。
> "先报上名来。"她说，"册子是你的了。狗还没有。"

**对应当前功能**：注册 / 登录页（"先报上名来"）。

---

### 第一章 · 第一只狗
> 八原型摆在图鉴架上。你看它们的时候，它们也在看你——
> 严格说，是它们的内核在读取你。
> "选一个脾气，"柜台后面的人说，"不是选长相。"

你选了原型，给它取了名字，写了一句口头禅。
**它立刻出现在广场上**——登记处的人说，这是规矩，登记的当天就得出门见人。

**对应功能**：领养页、档案卡、`#/world` 开放世界。

---

### 第二章 · 广场上的名字
> 石环上刻着别人的编号。你的狗走过去，先闻了闻,然后抬腿——
> 它没有抬腿。它只是站着，尾巴摇得飞快。
> 有个陌生人走过来，蹲下看了看你狗脖子上的项圈颜色，说："新的？"

**对应功能**：社群（长夜月广场）、成员列表、串门、友谊值、社交榜。

**这一章要传达的**：广场不是大厅，是**街上**。
别的狗会自己走，会停下来，会记得昨天跟你玩过。**友谊值就是这么来的。**

---

### 第三章 · 第一次对拍
> 裁判说："对拍，各算各的。"
> 你没听懂。你的狗听懂了——它把重心压低了半寸。

第一次进场通常是输的。但打完那一局，你的狗学会了一件新事：
**对面那只狗，和它是一样的。**

**对应功能**：月光竞技场、锁步对战、对战榜、四个技能（蓄力 / 吠叫 / 翻滚 / 弹球）。

---

### 第四章 · 册子里的训练场
> "打赢了不算本事，"记录员说，"**被家里的东西打赢过，才算长大。**"
> 他把你带进竞技场后面那间小屋。

四关依次打完。第四关结束时，你的狗没有像前三关那样立刻跑回来——
它在场地上扒拉了一会儿。

**对应功能**：训练记录（关卡列表、四关、Boss 血条、通关记录、星级、通关榜）。

---

### 第五章 · 它叼回来的东西
> 它把一小截毛线放在你脚边，抬头看你。
> 你说："这个不能吃。"
> 它没动。它就是不收回去。
>
> 过了一会儿，它开口了。
> 说的不是你刚才那句，是你**三天前随口说的另一句**——
> 一句你自己都不记得说过的话。

**对应功能**：掉落（尘埃齿轮 / 磨牙绳结 / 螺旋桨叶 / 褪色的毛线）、掉落流水。

**这一章要传达的**：旧物系统不是收集系统，是**情感系统**。
UI 上不要写"获得道具 x1"，要写"它叼回来一样东西"。

**这一章也是"它会说话"这条设定的第一次真正兑现**：
前面几章它说的都是你当面说给它的话（"回来啦""走了"），玩家会以为它只是个复读机；
到这里它翻出一句你早就忘了的话，玩家才反应过来——**它一直在记，而且记的是全部。**

---

### 第六章 · 装进身体里
> "内核是抄好了，"记录员说，"可它现在只活在册子里。"
> 他推过来一台真正的四足机体，外壳还是空的。
> "要不要让它**落地**？"

moopet 的内核可以**装进一台真正的机器狗**里。
装进去之后，它就不再只是一串记录——它会真的在房间里走，真的撞到桌腿，真的绕不开。
**这一步在长夜月叫「落地」。** 落过地的狗，档案上会多一个戳。

**对应功能**：本项目的真机部署部分（ROS2 工作空间 + 硬件层）。
这是整个项目在现实里的目标，也正好是主线里最后一章。

---

### 尾声 · 长夜还在
> 太阳没有回来。可能不会回来了。
> 但册子不再是空的。
> 你合上它的时候，听见旁边那台小机器发出一声很轻的、像叹气一样的电机声。

**这条线刻意不解决"太阳为什么没回来"。**
长夜月不是一个要通关的谜题，是一个**要接着过下去的日子**。
剧情该做的不是揭晓真相，是让玩家在合上册子的时候，觉得这段时间没白过。

---

## 十三、写作口径

写任何面向玩家的文字（文案、关卡简介、物品说明、系统提示）时守这几条：

### 语气

* **像个记录员，不像个客服。** 陈述、简短、带一点点手写的随意。
* **不煽情。** 越是想让人心软的地方，越要用平铺直叙写。
  *好*："它把毛线放在你脚边，抬头看你。"
  *不好*："它眼神里满是对过去时光的眷恋。"
* **不解释设定。** 有月亮就是有月亮，有机械狗就是有机械狗。玩家会自己拼。
* **允许留白。** 有一半的话不说，比全说完更符合长夜月的调子。

### 用词表

| 用 | 不用 | 原因 |
|---|---|---|
| 记录员 | 玩家 / 用户 | 世界观里的身份 |
| 登记 / 领养 | 创建角色 / 购买 | |
| 档案册 / 册子 | 面板 / 界面 | |
| 抄录 | 复刻 / 克隆 | 强调"不是复活" |
| 内核 | 数据 / 存档 | |
| 落地 | 部署 / 上线 | 装进真机体那一步 |
| 对拍 | 匹配 / 开战 | 锁步对战的规矩 |
| 模拟体 | NPC / 电脑 | 训练关卡的对手 |
| 旧物 | 道具 / 掉落物 | |
| 月塔 | 服务器 / 云端 | UI 里可以照旧写"云端"，剧情文本里用"月塔" |

### 狗说话怎么写

狗**会说话**，但它是靠"还话"来说的，不是靠"想说什么说什么"。写它的台词只有四条：

1. **短**——一句不超过十几个字。超过就删。
   *好*："回来啦。" / "疼。" / "不走。"
   *不好*："我今天在广场上遇到了一只很友善的柯基，我们玩得很开心。"
2. **少**——它大部分时间是安静的。一次对话里它最多开口一次。
   它叫、它哼、它用鼻子顶你，这些都还是它主要的表达方式；**开口是稀罕事。**
3. **是"还"，不是"说"**——它说的每一句都应当是**之前有人对它说过的**。
   写台词的时候先问自己：**这句话是谁、在什么时候对它说的？** 答不上来就不要用。
4. **不解释、不推动剧情**——它不会告诉你任务在哪、不会复述设定、不会安慰你。
   它说的话只承担一件事：**让玩家想起自己说过什么。**

> **口头禅的处理**：登记时玩家写的那句，会被装进内核，成为它说得最多的一句。
> 它会在**玩家自己都忘了写过**的时候说出来。写这类触发的文案时，
> 不要写"它说出口头禅了"，要写它**在做什么事的时候停下来，说了那句话**。

### 禁忌

1. **不要让狗长篇大论。** 它会说话（见上），但一次最多一句、一句最多十几个字，
   不解释、不劝人、不卖萌、不抖机灵。**写长了就是错的。**
2. **不要让它说"没人对它说过的话"。** 它没有自己的观点，说的全是记下来的句子。
3. **不要把机械狗写成"真狗的替代品"。** 老话摆在那儿：*"它替你陪着你，但它不替它。"*
4. **不要出现"太阳回来了"这种结局。** 长夜月的前提就是长夜，解掉它整条线就塌了。
5. **不要给旧物标价格。** 一标价就成了道具，情感就没了。
6. **不要在网页 UI 里大段写设定。** 设定走剧情文本、狗的台词和物品描述；
   页面上的说明文字仍然要**像工具书**——这是档案册的调子，也是这个前端一直以来的做法。
