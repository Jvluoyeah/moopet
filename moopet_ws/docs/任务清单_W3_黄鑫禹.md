## 一、本周任务（W3 · 8.17–8.23）

### 任务 0：上手 + 摸底（半天，本周一前完成）
- 跑 `python standalone_demo_w3.py --fast` 和 `--interactive`，把答题/连击/加点完整过一遍；
- 读 `exp_engine.py` 的 `QUIZ_COMBO_BONUS`（连击 5 → +50、10 → +100，免周上限）和 `quiz_bank.py` 的 `judge()` / 难度降档；
- 跑 `python src/moopet_dog/tests/test_quiz_exp.py`（6 个用例：连击/周上限/答题记录/成就）确认全过。
- **验收**：把演示时间轴记下来，标注"语音环节该插在哪一段"（出题播报、答对表扬、连错鼓励）。

### 任务 1：打通语音问答链路（命令行 demo 版）— 本周核心
- **目标（排期）**：ASR 出题 → 用户语音 → 判对错 → TTS 反馈。
- **复用**：W1 已选型 ASR/TTS（whisper / edge-tts）；判对错直接用 `quiz_bank.judge()`。
- **说明**：TTS 进 ROS 是 W4 李文扬接入的事；本周先在**命令行**把链路打通：出题（读题库文本/播报）→ 语音输入 → 判对错 → TTS 反馈音频。
- **验收**：命令行 demo 能完整问答一轮，打印判对错结果并生成反馈音频；连对 5/10 题有连击语音反馈。

### 任务 2：设计模拟测试场景集（至少 5 个）
- 基于演示时间轴设计 ≥5 个场景，例如：
  1. **新用户引导**：LV.1 使用指引全套 +100；
  2. **基础互动加点**：抚摸/散步逐项 +10、升级；
  3. **答题连击加餐**：连对 5 题 +50、10 题 +100；
  4. **连错 3 题降档**：难度从 3 降到 2；
  5. **等级解锁新科目**：LV.15 解锁 科学/编程、LV.20 解锁 自定义；
  6. **周上限封顶**：答题周上限 200 / 全局 2000。
- **验收**：每个场景有「输入序列 + 预期输出」，能在 `standalone_demo_w3.py --fast` 或 `--interactive` 里复现。

### 任务 3：验证连击 5/10 与奖励逻辑
- **复用**：`quiz_node` 的 `DEMO_CORRECT` 序列（10 连对 → 3 连错 → 收尾）、`QUIZ_COMBO_BONUS`、`test_quiz_exp.py`。
- **验收**：跑通并记录——连对 5 题 +50、10 题 +100（不计周上限）、连错 3 题难度降一档；结果写进本周测试报告。
