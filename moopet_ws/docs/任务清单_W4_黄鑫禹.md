## 一、本周任务（W4 · 8.24–8.30）

### 任务 0：上手 + 看新能力（半天，周一前完成）
- 跑 `python standalone_demo_w4.py --fast`，重点看四幕：性格演化 → 冷落与和好 → 主动关怀 → 仪式/纪念日/日记；
- 读 `docs/进度汇报_W4.md` 第五节（验证结果），知道哪些已在单测里锁死、哪些是**留给手感调的参数**；
- 记住几个默认参数（后面调参就是调它们）：性格轴 +6/事件、衰减 1/事件、闲置 3/天、分界 55；账户 +2/互动、-5/闲置天、冷淡线 30、关怀阈值 2 小时。
- **验收**：给李文扬一句反馈"哪一幕感觉最对、哪一幕最别扭"。

### 任务 1：角色串联演示 — 本周核心
- **目标**：把「表情 → 决策 → 动作 → TTS」全链路走一遍，形成一份可重复的演示走查清单。
- **怎么走**：
  - Ubuntu 上 `bash scripts/start_demo.sh`（背包包已含 W4 新增的 `tts_node`，demo 模式打印 🔊 播报）；
  - 逐场景过：摸头（决策→TTS）、握手（决策→/dog/action 动作）、答题对/错、长沉默触发主动关怀、早安/晚安窗口、里程碑、自定义纪念日；
  - 每个场景记录：触发方式、反应内容、TTS 是否出声、动作是否执行、有无卡顿/漏触发。
- **验收**：一份《串联演示走查表》（场景 × 结果 × 问题），**无 P0 卡点**即通过；Windows 侧可先用 `standalone_demo_w4.py` 对台本。

### 任务 2：手感实测
- **目标**：从"用户陪狗一整天"的视角实测节奏。
- **测什么**：
  - 摸头几次开始"变性格"？变化播报出现的时机自然吗？
  - 冷落两小时才关怀——演示时等得起吗？要不要给个演示用的短阈值（如 5 分钟）？
  - 早安/晚安的话术按性格切换，听起来贴不贴？
  - 账户 +2/-5 的速率，"一天正常陪伴"大概落在哪个档位？
- **验收**：结论写成一句话/组（例如"账户太钝/太敏感，建议 +2→+3"），带场景依据。

### 任务 3：调参建议清单
- **目标**：把任务 2 的结论变成可执行的调参建议。
- **交付**：一张表——参数名 / 现值 / 建议值 / 理由 / 影响的场景。参数集中在
  `src/moopet_dog/moopet_dog/decision/decision_engine.py` 顶部常量区，改一处全局生效；
- **验收**：李文扬按表调完参数，demo 复跑一遍，你确认"手感对了"。

### 任务 4：汇报素材（顺手）
- 把串联演示里**最像"活物"的 3 个瞬间**截录下来（如冷落后主动开口、变性格时说"请多指教"），W5 综合演示和比赛视频都用得上。
