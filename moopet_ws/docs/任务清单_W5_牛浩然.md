### 任务 1：后端·火花 API — 本周核心
- **目标**：火花状态/续火/熄灭/挽回 的 REST 接口。
- **复用**：`SparkEngine.get_spark()/register_activity()/settle_missed_days()/remind_due()`。
- **接口建议**（字段以 SparkEngine 返回为准，别另造口径）：
  - `GET /api/spark` → `get_spark()` + 今天是否该提醒
  - `POST /api/spark/activity`（互动事件）→ `register_activity` + 每日任务 `report_event`
  - `GET /api/spark/reminder` → `remind_due(now)`（web 定时拉，或按 18/21/23 前端本地定时）
- **验收**：连续陪伴天数/档位能查、互动后续火/断档熄灭/挽回状态正确返回。

### 任务 2：后端·每日任务 + 成就查询 API
- **目标**：每日任务面板数据 + 成就徽章数据。
- **复用**：`SparkEngine.daily_tasks()/report_event()/tasks_all_done()`；成就表
  `achievement / user_achievement`（W2 已建，`exp_engine._check_achievements` 在解锁写入）。
- **接口建议**：
  - `GET /api/daily_task` → 当天任务 + 进度 + target + done
  - `POST /api/daily_task/report`（source）→ `report_event`（答对才报 quiz、通风完成才报 ventilate）
  - `GET /api/achievements` → 全部成就定义 + 是否已解锁（联合查询两张表）
- **验收**：任务进度随互动增长、全部完成返回 done；成就徽章页能列出已解锁/未解锁。

### 任务 3：后端·签到 / 抽奖 API
- **目标**：签到 + 抽奖（含 200 次保底），抽奖经验不计周上限。
- **复用**：`SparkEngine.sign_in()/draw_lottery()/lottery_chances()` +
  `ExpEngine.lottery_gain(amount)`（已加好 weekly-exempt，累计经验/等级，不计周上限）。
- **接口建议**：
  - `POST /api/sign_in` → `sign_in()`（每天 1 次）
  - `GET /api/lottery/chances` → 当天剩余机会
  - `POST /api/lottery/draw` → `draw_lottery()` + 命中后调 `exp_engine.lottery_gain(exp)`
- **验收**：签到 +1、任务完成 +2、抽奖消耗机会并出奖、经验到账且**周经验不变**、200 次保底。
- ⚠️ 保底计数在 `spark_meta.pity`，`draw_lottery` 内部维护，**后端不要另存一份**。
