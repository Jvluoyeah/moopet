### 任务 1：端到端回归回放 — 本周核心
- **目标**：把「遛狗 → 抚摸 → 答题 → 升级 → 火花」一整条链路串起来，出一份可重复的回放清单。
- **怎么走**：
  - Windows 上跑 `standalone_demo_w5.py --fast` 打底；Ubuntu 上 `bash scripts/start_demo.sh`
    走 ROS 全链路（背包感知 → 经验结算 → 答题 → 决策 → 火花 → TTS）；
  - 一整套回放路径：
    1. 遛狗加经验（`/dog/odom` 满 50m +10，周上限 500）
    2. 抚摸/握手/呼唤加经验 + 驱动火花续火 + 每日任务进度
    3. 答题答对加经验（等级解锁题库、连击 5/10 奖励）
    4. 升级 → 等级里程碑庆祝 + 里程碑解锁玩法（LED/肤位）
    5. 火花：连续陪伴续火 → 满 7 天升档 → 断档熄灭 → 回归挽回
    6. 每日任务全部完成 +2 抽奖机会 → 签到 +1 → 抽奖出奖加点（周经验不变）
- **验收**：一份《端到端回放走查表》（环节 × 结果 × 问题），**无 P0 卡点**即通过。

### 任务 2：边界用例（顺手）
- **跨日**：`settle_missed_days` 断档熄灭、日记跨日写昨日、每日任务按日期刷新——
  手动把系统日期拨到次日/隔天验证；`SparkEngine` 有 `date` 参数可直接传不同日期测。
- **跨周**：周上限聚合按周一 `week_start`；抽奖经验不计周上限（`week_exp` 不涨）；
  quiz 周上限 200、全局 2000 封顶。
- **重复触发防重复加点**：
  - 火花同档提醒当天只提醒一次（`mark_reminded` 去重）；
  - 每日任务加成只发一次（`task_bonus` 标记）；
  - 签到每天只签一次；抽奖无机会时 `draw_lottery` 返回 `ok=False` 不加点；
  - 使用指引 `guide` 只加一次经验（W2 已有逻辑）。
- **断网**：模拟 `/backpack/heartbeat` 超 15s → 狗侧判定离线（W6 才完善重连，
  本周先确认日志有告警即可）。
- **验收**：上述边界各至少 1 条可复现用例，结果记录在走查表。

### 任务 3：手感/节奏反馈
- **测什么**：
  - 三档提醒（18/21/23）一天催三次会不会太烦？话术语气贴不贴？
  - 每日任务 2 个是否合适？难度（target）合理吗？
  - 抽奖概率节奏：一般玩家几天能攒到 200 次保底？（可写个小脚本模拟抽 N 次看分布）
  - 断档一天就熄灭——是不是太狠？要不要给"宽限/挽回"更温和的口径？
- **交付**：一句到一组结论（例如"18 点那档语气太重，建议更轻"），带场景依据。
