### W2 · 模拟感知层（✅ 全套 demo 完成）

**接口规范**（李文扬条目）
- `docs/interface_spec.md`：各 Topic 消息字段与频率、7 种经验来源→感知事件归一映射、双机部署口径
- 心跳 `/backpack/heartbeat`（**5s**）、里程 `/dog/odom`（**10Hz**，遛狗统计口径）

**仿真感知节点**（背包盒子，均有 `--demo` 时间轴脚本模式）
- `audio_node` 模拟语音命令（intent：呼唤/指引/散步/握手/聊天）
- `vision_node` 模拟表情识别 + 动作识别（握手）
- `env_node` 模拟空气质量 ENS160/PMS5003（含 warning_level + 通风完成）
- `touch_node` 模拟 MPR121 触摸分区（头部/背部抚摸）
- `heartbeat_node` 背包在线心跳

**狗本体节点**
- `odom_node`：10Hz 里程发布，`/dog/cmd/walk` 走停控制，demo 自动遛狗
- `exp_engine_node`：订阅全部感知事件 → 归一结算 → 发布 `/dog/state` + 提供 `/dog/action` 服务
- `state_mgr_node`：订阅状态/心跳，实时打印「狗狗状态卡」

**经验结算引擎**（黄鑫禹条目，承接联调）
- 7 种来源归一加点：散步/通风/投影/通讯/抚摸/握手/呼唤（含各自周上限）
- 周上限统计（按周一聚合）、全局每周上限 2000
- 衰减惩罚（连续 7 天未使用逐天衰减，**最低 30 级**）
- 升级判定（等级曲线按 狗2.md 表格）+ 一次性成就解锁（7 项）
- SQLite 持久化（11 张表，对齐 牛浩然 W1 数据模型）

## 五、demo 演示效果（预期）

1. 背包 5 节点启动：心跳 5s 一帧、语音/表情/空气质量/抚摸按脚本时间轴触发；
2. 狗侧里程 10Hz，每累计 50m → 散步 +10；
3. 各互动事件实时进入结算引擎加点，升级时打印 `[升级] LV.x -> LV.y`；
4. `state_mgr` 打印状态卡（等级/累计/本周经验/心情/连续天数/背包在线）；
5. demo 场景自动调用 `/dog/action`（投影/通讯/握手）各 +10，形成完整闭环。

## 六、双机联调说明

- 同一局域网 + 相同 `ROS_DOMAIN_ID`：狗机跑 `--machine dog`，背包机跑 `--machine backpack`；
- 跨机可见验证：`ros2 topic echo /backpack/heartbeat`（狗看背包）、`/dog/odom`（背包看狗）；
- 防火墙需放行 Fast-DDS 默认 UDP 端口段 7400-7500。
