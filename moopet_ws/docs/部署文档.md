# 部署文档（Ubuntu 22.04 + ROS2 Humble）

本目录为养成系机械狗软件开发（李文扬 W1 地基 + W2 模拟感知层 + W3 答题/基础闭环全套 demo）。

## 一、环境要求

| 项 | 要求 |
|----|------|
| OS | Ubuntu 22.04（x86_64 开发机 / arm64 为 RK3588） |
| ROS2 | Humble（ros-base 即可，Python 节点） |
| Python | >= 3.10 |
| 依赖 | `colcon-common-extensions`、`python3-argcomplete`、`python3-pip` |

## 二、安装 ROS2 Humble

```bash
sudo apt update && sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8

sudo apt install -y software-properties-common
sudo add-apt-repository universe
sudo apt update

# 加入 ROS2 源
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

sudo apt update
sudo apt install -y ros-humble-ros-base ros-dev-tools
sudo apt install -y python3-colcon-common-extensions python3-argcomplete
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

验证：

```bash
ros2 --help
ros2 topic list        # 无报错即环境就绪
```

## 三、编译自定义消息与节点

```bash
cd <本目录>/moopet_ws
source /opt/ros/humble/setup.bash

colcon build --symlink-install --packages-select \
  moopet_interfaces moopet_backpack moopet_dog
source install/setup.bash
```

验证每条自定义接口（W1 冒烟 1）：

```bash
ros2 interface show moopet_interfaces/msg/HeartbeatMsg
ros2 interface show moopet_interfaces/srv/DogAction
ros2 interface show moopet_interfaces/action/TtsSpeak
```

## 五、W3 全套 demo（一键启动）

```bash
cd moopet_ws
bash scripts/start_demo.sh          # 单机全自动：仿真感知 → 加点 → 升级 → 答题 → 决策
bash scripts/stop_demo.sh           # 手动停止
```

预期现象（logs/ 各节点日志）：

1. 背包 5 个节点上报心跳、语音、表情、空气质量、抚摸；
2. 狗侧里程 10Hz，累计 50m → 散步 +10 经验；
3. 各互动事件 → 经验结算引擎加点，触发升级时打印 `[升级] LV.x -> LV.y`；
4. `state_mgr` 打印「狗狗状态卡」（等级/经验/心情/连续天数/背包在线）；
5. demo 场景自动调用 `/dog/action`（投影/通讯/握手）与 `/dog/combo`（判题桥接）；
6. `quiz_node`（demo 模式）等狗升到 LV.3 后自动出题/作答，连击 5/10 奖励、连错 3 题难度降档，并发布 `/dog/decision/event`；
7. `decision_engine_node` 订阅决策事件，经行为决策引擎（BT 骨架）路由出反应，联动 TTS 与 `/dog/action`。

> 无 ROS 环境下，可用 `python standalone_demo_w3.py`（W1→W2→W3 一条时间轴）直接演示。

## 六、双机联调（狗 ↔ 背包）

两台设备接入同一局域网，各机设置相同 ROS_DOMAIN_ID：

```bash
# 狗机（RK3588/开发机）
export ROS_DOMAIN_ID=42
cd moopet_ws && bash scripts/start_demo.sh --machine dog

# 背包机
export ROS_DOMAIN_ID=42
cd moopet_ws && bash scripts/start_demo.sh --machine backpack
```

验证跨机可见：

```bash
ros2 topic list                       # 两台都能看到全部 topic
ros2 topic echo /backpack/heartbeat   # 狗机能看到背包心跳
ros2 topic echo /dog/odom             # 背包机能看到狗里程
```

> 提示：若跨机发现失败，检查防火墙（`sudo ufw allow 7400:7500/udp`，Fast-DDS 默认端口段）或配置 DDS 多播。
