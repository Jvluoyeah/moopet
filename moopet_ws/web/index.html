W4 · 02 // 情感账户 + 主动关怀

W4 成果②

长期忽视会伤心；它会在你沉默时主动开口。

0–30 冷淡30–70 平衡>70 依赖

情感账户 0~100

  • 正向互动 +2（摸头/握手/散步/答对…），封顶 100
  • 闲置一天 -5；双轴性格同步淡化 -3/天
  • <30 冷淡：不再主动搭话（"长期忽视减少主动互动"，设计行为）
  • 和好机制：回来多互动，账户逐步回温
demo：2 天冷落 64→54→20 冷淡，摸头×6 回 32

主动关怀 · 长沉默 ≥2h

  • 平衡期：「主人好久没理我了…有点想你，要不要摸摸我？」
  • 依赖期：「主人你去哪啦，我等你好久啦！」
  • 深夜 23-6 点：「夜深了，主人早点休息哦，我守着你。」
  • 冷淡期：沉默（设计行为，非缺陷）
  • 触发入口：on_tick 周期检查（节点 60s 定时器）

demo 实测 · 冷落 → 和好：2 天不互动账户下滑进冷淡区（不再主动）→ 回来摸头×6 → 回到平衡。全程数值可复现、可单测（19 项 W4 单测覆盖账户增益/封顶/衰减/档位/抑制）。

情感账户越投入回应越丰富；长期忽视掉进冷淡区就不再主动搭话（设计行为）；回来多互动会回温（和好机制）。
