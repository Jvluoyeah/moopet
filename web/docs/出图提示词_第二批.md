## 零、先定三件事，不然出来的图我没法用

### 1) 视角：战斗帧必须是**纯侧面**

已有的四形态是 3/4 侧视（图鉴、大世界立牌用）。但战斗是**横板卷轴**，
跑动/扑咬用 3/4 视会看起来在"斜着走"。所以第二批全部要求：

> **纯侧面视角，头朝右，平视，无透视，全身完整入镜**

### 2) 画布与基线：和第一批完全一致

* 画布 **正方形**，狗（含耳朵）高约占 **78%**，脚底压在同一条水平基线上
* 一格里只放一只狗，四周留白 ≥10%，**不许贴边**（贴边就一定会被切到）
* 背景：**纯白**或透明。纯白也行，我用洪水填充抠

### 3) 交付：**一帧一个文件**

> ⚠️ **这条改过。** 原来写的是"一个动作一张横条图（一行 N 格）"，
> 实测翻车：让模型在一个提示词里画 6 帧跑动循环，它给的是**五张一模一样的画**，
> 第 6 格还是空的——出图模型没有时间概念，连续动作它理解不了，只会复制同一张。
>
> 现在改成 **一帧一张图、单独出**，文件名带编号：

```
web/public/breeds/<code>/actions/run_01.png  run_02.png  run_03.png  run_04.png
web/public/breeds/<code>/actions/attack_01.png  attack_02.png  attack_03.png
web/public/breeds/<code>/actions/jump_01.png  jump_02.png
web/public/breeds/<code>/actions/hurt.png
```

* 帧数：跑动 **4 帧**就够（接触 / 下沉 / 通过 / 抬起），不必求 6 帧
* 一个动作的所有帧**共用同一个缩放系数**（切图脚本按动作分组统一处理）
* 出图比例 **1:1**，2K
* 横条/网格我仍然能切（`split_cells` 两套都认），但**不推荐**——见上面的翻车原因
* 完整的萨摩耶逐帧提示词见 `docs/出图提示词_萨摩耶.md`；
  其他七个品种照它的动作描述改"品种句"即可

## 一、通用提示词（每张都要带）

### 风格前缀（中文）

```
木刻版画 / 橡皮章贴纸风格，粗墨线闭合轮廓（线宽约为画布高的 1.4%），
平涂实色，无渐变、无阴影、无写实毛发、无纸纹，
实心小圆点眼睛，简洁几何形状，边缘干净，剪影清晰
```

### 风格前缀（English）

```
woodcut / linocut sticker style, bold uniform black ink outline (~1.4% of canvas height),
flat solid color fills only, no gradient, no shading, no fur detail, no texture,
solid dot eyes, simple rounded geometric shapes, clean closed silhouette
```

### 技术后缀（中文）

```
纯侧面视角，头朝右，平视，无透视；一只狗完整入镜，居中，四周留白充足不贴边；
纯白背景；正方形画布，狗高约占画布 78%，脚底压在同一条水平基线上；无文字无水印
```

### 技术后缀（English）

```
PURE SIDE VIEW, facing right, orthographic, no perspective; one single dog, fully in frame,
centered with generous margin, never touching the edges; plain white background;
square canvas, dog occupies ~78% of canvas height, feet on one fixed horizontal baseline;
no text, no watermark
```

### 负面词（每次都要带）

```
写实毛发，照片，3D 渲染，塑料高光，渐变，投影，落地阴影，背景风景，多只狗，
文字，水印，签名，emoji，动漫大眼睛，睫毛，多余的腿，模糊，噪点，
速写断线，非闭合轮廓，出血被裁，贴边
```

```
realistic fur, photograph, 3D render, glossy plastic, gradient, drop shadow, ground shadow,
background scenery, multiple dogs, text, watermark, signature, emoji, anime eyes,
extra legs, blurry, noisy, broken sketchy lines, open contours, cropped edges
```

## 三、动作片段（P1 · 战斗动作帧）

> **一帧一条提示词、单独出**（原因见上面第 0 节）。下表是每一帧的姿态描述，
> 直接接在品种片段后面用。跑动从 6 帧减到 **4 帧**。

| 文件 | 姿态描述（插在品种片段前面/后面都行） |
|---|---|
| **run_01** | 四脚奔跑的"接触"瞬间：前爪刚触地，前腿向前伸到最远、后腿向后蹬到最远，四条腿张开成一个大大的 X 形，身体被拉得最长最平，头向前伸，耳朵向后飘 |
| **run_02** | 四脚奔跑的"下沉"瞬间：前腿弯曲承重，整个身体压到最低、最扁，后腿收拢到肚子正下方只露出一点点，头略低，尾巴向下沉 |
| **run_03** | 四脚奔跑的"通过"瞬间：后腿在身体正下方完全伸直支撑（像一根柱子），前腿完全折起贴住胸口，另一条后腿向前摆出半步，身体重心最高 |
| **run_04** | 四脚奔跑的"抬起"瞬间：后腿向后蹬成一条笔直的斜线（与身体约 45°），前腿向前上方甩出，四条腿全部离地、身体前高后低、脚下不画地面线 |
| **attack_01** | 扑咬起手：上半身抬起、后腿弯曲下蹲、身体向后坐（重心压在屁股上），头高高抬起、嘴闭紧、耳朵竖起来朝前 |
| **attack_02** | 扑咬命中：身体向前扑出去、两条前腿完全离地向前伸、嘴张到最大露出两颗小尖牙、耳朵向后压、后腿在身后蹬直、身体与地面约成 30° 角 |
| **attack_03** | 扑咬收招：前爪重新落地、四肢着地、嘴已合上、身体略前倾、头低下来、耳朵放松、尾巴垂着 |
| **jump_01** | 起跳上升：四肢全部收拢紧贴身体（缩成一团）、身体向前上方倾斜、耳朵向后飘、尾巴上扬、脚下不画地面线 |
| **jump_02** | 下落：两条前腿向前下方伸出去够地面、两条后腿向后蹬直、身体略微后仰前低后高、头向下看、耳朵向后、脚下不画地面线 |
| **hurt** | 受击后仰：头扭向左边（被打退的方向）、身体向后倾斜、眼睛闭成两条短横线、前面一条腿抬起来离地、耳朵向后倒、尾巴夹下去 |
| **down** | 被打败躺在地上：身体侧躺、四肢半蜷着摊开、头枕在地上、眼睛画成两个小叉（×）、耳朵摊平、尾巴软软摊在地上；要一眼看出是"输了"，不是"在睡觉" |
| **dash_01** | 全力冲刺：身体压得非常低几乎贴地、四条腿向后蹬成流线型、身体拉得又长又扁、头向前伸得很低、耳朵完全向后贴、身后 3~4 条墨色速度线（只能是黑色细线） |
| **dash_02** | 团身翻滚：身体紧紧蜷成一个圆形毛球、四条腿全部收进身体里看不见、只有头和尾巴从球两端露出来、头朝下埋着、身后一道墨色弧线 |
| **skill_01** | 坐着蓄力：屁股坐地、上半身挺直、两条前腿抬起来离地悬在胸前、头微微上仰、嘴张开像在叫、身体周围浮着 4~6 个小墨点和几根短线（特效只能是墨色） |
| **skill_02** | 释放：两条前腿向前挥出去、身体前倾、嘴张到最大像在吠叫、耳朵向后压、身体正前方一圈向外扩散的墨线波纹（只能是墨色线条） |
| **guard** | 防御架势：四条腿分开站得很宽、重心压得很低、身体微微蜷起来、头低下去、两条前腿交叉挡在身前、眼睛画成两条横线、耳朵向后贴、尾巴收进肚子下面 |

## 五、建议的生成顺序（别一次出上百张）

| 批次 | 内容 | 张数 | 为什么先做这些 |
|---|---|---|---|
| **1** | 萨摩耶 的 run 4 帧 + attack 3 帧 + hurt | 8 | 先在一个品种上把"逐帧出 → 切图 → 进游戏"整条链路跑通 |
| 2 | 柯基 同上 | 8 | 一只浅色蓬松、一只橘色短腿，**覆盖两种比例极端** |
| 3 | 其余 6 品种的 run + attack | 42 | 战斗里最常出现的两个动作 |
| 4 | 全部品种的 jump / down / dash / skill / guard | 8×7 | |
| 5 | 关卡 Boss（见下） | 4~6 | 现在训练关卡的 Boss 还是拿玩家的狗顶替的，观感最弱的一环 |
| 6 | 小件（见下） | ~10 | 不急 |

**先出第 1 批（萨摩耶 8 张）**——比例、基线、切图缝隙、播帧观感都没问题之后，
再按同一套姿态描述批量出其他品种，能省掉"出完上百张才发现都要返工"的风险。

## 六、关卡 Boss（P3 · 按**关卡**分，不分品种）

训练关卡的 Boss 现在全部借用玩家品种的形象，这是目前战斗里最弱的一环。
四个 Boss 走"家用机械失控"的路子，**配色不要用上面那 8 个毛色**，
统一走铁锈 + 黄铜 + 铁灰，一眼就能和玩家区分开：

**Boss 专用色板**：锈红 `#8C3B2E` / 黄铜 `#B8892F` / 铁灰 `#4A4640` / 锈斑 `#6B5B4A`
