| 已有 | 用途 |

| `四种形态` 趴下 | 现在是倒地的替身 |

**这五张继续当参考图用，而且这次要拧紧**：出下面每一条时，把 `pic/金毛/主图.png`
作为**参考图**丢进去（不是"风格参考"那种弱绑定），强度 **0.65~0.8**；
平台若有"风格强度/参考强度"就往上拉。

> ⚠️ **不拧紧就会出现风格漂移**：实测只靠文字描述时，模型把"木刻版画"理解成了
> **黑白排线版画**，出的哈士奇是一张满是刻痕阴影、写实解剖、像狼的线稿——
> 和参考图完全不是一套东西。文字描述再准也压不住，必须靠参考图拉住。
> 现在的每条提示词里都加了"严格沿用参考图画风，只改姿势"这句，
> 负面词里也加了"线稿 / 素描 / 排线 / 灰度 / 黑白 / 写实解剖 / 狼"这一串。

**出图设置**
* 比例 **1:1**（智能比例 → 正方形），2K
* **一帧一张图，不要拼网格**
* 提示词里**不要**写"一行 N 格""2×3 网格"这类话

> ⚠️ 上一轮就是栽在这里：让模型"一个提示词里画 6 帧跑动循环"，
> 出来的是**五张一模一样的画**，第 6 格还是空的。
> 出图模型没有时间概念，连续动作它理解不了，只能复制同一张。
> 所以：**一帧一条提示词、单独出**，并且把每帧的剪影差异写得足够极端。


### 还有一件事：**不同动作要用不同的参考图**

一直拿 `主图.png` 当参考，姿势差得远的时候模型就会自己"发明"——这是上一轮
哈士奇 `skill_02` 出成长腿尖嘴狗的另一个原因。手上已经有 5 张不同姿势了，按下面的表挑：

| 出这张 | 用哪张当参考图 | 为什么 |
|---|---|---|
| `run_01`~`run_04`、`attack_01`~`03`、`jump_01`~`02`、`dash_01`、`hurt`、`guard` | `pic/<品种>/主图.png` | 通用姿势，用最完整的那张 |
| `skill_01`、`skill_02` | `public/breeds/<code>/forms/paw.png`（挥手） | **本来就抬着前爪**，和放技能的起手最接近 |
| `down`、`lose` | `public/breeds/<code>/forms/lie.png`（趴下） | 已经是躺着的姿势 |
| `win`、`emote_*` | `public/breeds/<code>/forms/face.png`（正面） | 面向镜头，表情/结算更贴 |
| `dash_02`（翻滚） | `forms/lie.png` + `主图.png` 都给 | 蜷成一团介于两者之间 |

> 参考图给得越贴，模型自由发挥的空间就越小，画风就越稳。
> 强度仍然建议 **0.65~0.8**。

## 二、通用块（每条提示词里都已经写进去了，这里只是备查）

**风格句**
```
卡通贴纸风格：纯平涂色块 + 粗黑描边，全图没有任何明暗与纹理——

整张图只有"黑色描边 + 2~3 种平涂颜色"（色值见下方的品种句），没有任何中间调
```

**规格句（动作帧）**
```
纯侧面视角，头朝右，平视，无透视，完整入镜、居中，四周留白不贴边；
纯白背景，正方形画布，狗高约占画布 78%；
狗的下半身靠近画布下缘（下方留出约 10% 空白），画面里不要出现地面线、阴影或边框
```

> ⚠️ **千万不要写"脚底压在一条水平基线上"这种话。** 实测模型会把它当真，
> 在图片底部**画一条灰色地面带**出来。那条带子颜色和背景不同，抠图时会被当成"内容"保留，
> 还会撑满整行把分格算法搞崩——第一次实测一张图被切成 **36 格、每格只有 9% 大小**，等于报废。
> 现在改成"下半身靠近画布下缘 + 下方留白"，并把这些写进负面词：
> **地面线、水平线、灰色条带、边框、白框、界面元素**。

**金毛品种句**
```
一只金毛寻回犬，完全垂耳，羽状长尾，敦实匀称，中等方钝口鼻，
金黄毛 #E4C07A 配浅黄 #F2E0B6，深色鼻 #2E2A22，脖子上一圈细项圈挂小圆牌
```

**负面词**
```
写实毛发，照片，3D 渲染，渐变，投影，落地阴影，地面阴影，背景风景，多只狗，
文字，水印，签名，emoji，动漫大眼睛，多余的腿，模糊，噪点，速写断线，非闭合轮廓，裁切，贴边
```

> **两个针对金毛的专门提醒**（每条提示词里都带了，别删）：
> 1. **尾巴是羽状的蓬松大尾、耳朵明显下垂**（不是立耳也不是半折耳）；
>    毛色平涂成两种金黄就行，**别画成渐变**——渐变会破坏平涂贴纸的语言。
> 2. **技能与冲刺的特效只能是墨色线条和墨点**，不要彩色光效/发光/粒子——
>    那和"羊皮纸 + 木刻"的整体语境冲突。

## 十三、交付与命名

一张一帧，放进 `pic/金毛/actions/`（表情单独放 `pic/金毛/emotes/` 也行）：

```
pic/金毛/actions/
  run_01.png   run_02.png   run_03.png   run_04.png
  attack_01.png   attack_02.png   attack_03.png
  hurt.png
  jump_01.png   jump_02.png
  down.png
  dash_01.png   dash_02.png
  skill_01.png   skill_02.png
  guard.png
  win.png   lose.png
pic/金毛/emotes/
  emote_happy.png  emote_curious.png  emote_angry.png  emote_sleepy.png
```

* **一帧一个文件**，不要再拼网格
* 文件名严格照上表（我的切图脚本按名字认，`_01/_02` 会自动按顺序排）
* 多出几张没关系，命名规则对了就能接

出好告诉我一声，我会：切成逐帧 → 进 `public/breeds/golden/actions/` →
战斗按状态播帧（跑动循环 / 扑咬三段 / 跳跃分上升下落 / 受击定格）。

**没出的动作自动继续用现在的静态图**，所以出一组接一组，不会青黄不接。
