## 一、一句话定位

**一只木刻版画风格的机械狗**：粗墨线勾出闭合轮廓，里面平涂实色，像印在羊皮纸档案册上的一枚印章。

不是写实宠物、不是 3D 渲染、不是毛绒玩具。整个前端是"羊皮纸档案册"（40px 网格底纹 + 纸纤维噪点 + 印章红/墨水蓝），狗必须和这套纸面是**同一个语境**：它是印上去的，不是贴上去的。

## 二、风格锚点

### 线条
| 项 | 口径 |
|----|------|
| 线宽 | 统一，约等于**画布高度的 1.4%**（1024px 图 → 约 14px） |
| 线色 | 墨黑 `#111211`（不要纯黑；夜里换 `#EFE9DC`） |
| 线头 | 圆头圆角（round cap / round join），不要尖角毛刺 |
| 轮廓 | **必须闭合**，不能出现断线、虚线、速写式重复线 |

### 填色
* **平涂实色**，一只狗最多 6 个色块
* **不要**：渐变、投影、内阴影、写实毛发笔触、噪点、纸张肌理（纸纹由页面负责，图里不要带）
* 高光只允许用"浅色块"表达，不允许用白色半透明渐层
* 落地阴影**单独一层**（或者干脆不画，我在引擎里挂椭圆投影）

### 造型
* 头略大、腿略短（chibi 2.5 头身），轮廓简单到"远看是个剪影也能认出品种"
* 眼睛是**实心小圆点**，不要高光大眼、不要睫毛、不要动漫眼
* 嘴：一条短线 + 一个小弧，不要牙齿、不要吐舌头（除非动作帧需要）

### 禁止项（出现即返工）
❌ emoji　❌ 文字 / 水印 / 签名　❌ 背景风景　❌ 多只狗同框
❌ 3D 渲染感 / 塑料高光　❌ 写实照片感　❌ 渐变色　❌ 出血被裁的耳朵和尾巴

## 三、全局比例与骨架（**这条最重要**）

所有立绘共用一张 **200×200 的画布坐标系**（出图时按 4 倍或 5 倍分辨率出，即 800×800 / 1024×1024，我这边等比缩）：

```
┌─────────────────────────┐  y=0
│        留白 12%          │
│      ╭───╮  ← 头顶       │  y≈24   耳朵尖最多到这里
│      │ 头 │              │
│   ╰──┴───┴──╮           │
│   身体       │           │
│   ╰──┬───┬──╯           │
│    腿 腿   ← 脚底         │  y=182  ★ 基线，所有狗都压在这条线上
│        留白 9%           │
└─────────────────────────┘  y=200
```

| 项 | 数值 | 说明 |
|----|------|------|
| 画布 | 正方形，透明底（PNG-32） | 不支持透明就出**纯白底**，我自己抠 |
| 狗的朝向 | **头朝右**，3/4 侧坐姿 | 与参考图一致；换方向我在代码里镜像 |
| 狗的高度 | 含耳朵占画布高的 **78%~80%** | 不同品种必须一致，否则站一起会有的高有的矮 |
| 脚底基线 | 距底边 **9%**（y=182/200） | 大世界立牌、对战单位都按这条线贴地 |
| 左右留白 | 各约 **10%** | 尾巴和鼻子不许顶到边 |
| 锚点 | `ground = (100, 182)`、`head = (140, 76)` | 写在 `breed.json` 里，气泡/名牌挂 `head` |

> ⚠️ 大世界和竞技场里，狗是**竖着插在地上的立牌**（billboard）。所以立绘要能"站在一条水平线上"，不能有透视俯视感——**平视或极轻微的俯角**，不要画成从上往下看。

## 四、八个品种的特征表

形状差异要**一眼可辨**，只靠毛色区分是不够的（在小尺寸下会糊成一片）。

| code | 品种 | 耳 | 尾 | 体型 | 口鼻 | 斑纹 |
|------|------|----|----|------|------|------|
| `samoyed` | 萨摩耶 | 立耳（尖） | 卷尾（贴背） | 蓬松 | 短 | 无 |
| `border_collie` | 边境牧羊犬 | 半折耳 | 长垂尾 | 瘦长 | 长 | 额头白筋（blaze） |
| `golden` | 金毛寻回犬 | 垂耳 | 羽状大尾 | 敦实 | 中 | 无 |
| `corgi` | 柯基 | 大立耳 | 短尾（圆） | **低矮长身** | 中 | 胸口白斑 |
| `shiba` | 柴犬 | 立耳 | 卷尾 | 瘦长 | 尖 | 胸口白斑 |
| `german_shepherd` | 德国牧羊犬 | 尖立耳 | 长尾 | 敦实 | 长 | 背部黑鞍（saddle） |
| `husky` | 哈士奇 | 立耳 | 羽状尾 | 敦实 | 中 | 面罩（mask） |
| `bichon` | 比熊 | 垂耳 | 卷尾 | 蓬松（圆球感） | 短 | 无 |

**最需要拉开差距的三只**：柯基（腿短到夸张、屁股圆）、德牧（背线倾斜、马鞍纹）、哈士奇（面罩 + 灰蓝毛）。
**最容易画糊的一对**：萨摩耶 vs 比熊——萨摩耶要尖立耳、微笑嘴线；比熊要垂耳、整个头是圆的。

### C. 横板对战动作帧（P1，先做柯基或萨摩耶一套）

对战视角是**纯侧视横板**（相机跟着狗平移，背景是视差卷轴），所以这一套全部是**纯侧面、头朝右、平视**。

**规格**：512×512 PNG 透明底，**每一帧的脚底基线必须在同一像素行**（否则跑起来会上下抖），身体中心也尽量对齐同一竖线。

| 编号 | 名称 | 帧数 | 说明 |
|------|------|------|------|
| C01 | `idle` | 2 | 站立呼吸，第 2 帧整体下沉 2~3%，尾巴/耳朵轻微差位 |
| C02 | `walk` | 4 | 慢走循环，接触→下沉→通过→抬起 |
| C03 | `run` | 6 | 冲刺循环，四脚离地那一帧要有腾空感 |
| C04 | `jump_up` | 1 | 起跳，四肢收拢，身体前倾 |
| C05 | `jump_fall` | 1 | 下落，前腿前伸准备落地 |
| C06 | `land` | 1 | 落地压缩，身体压扁一点 |
| C07 | `attack_1` | 2 | 第一段：抬头预备 → 前扑咬 |
| C08 | `attack_2` | 2 | 第二段：转身甩尾横扫 |
| C09 | `attack_3` | 3 | 第三段：跃起下砸（要有明显的起手定格） |
| C10 | `skill_cast` | 2 | 放技能的起手 + 释放；建议带一点信号柠檬 `#D5FF52` 的能量线 |
| C11 | `dash` | 2 | 冲刺，身体拉长、背后带速度线 |
| C12 | `guard` | 1 | 防御，重心压低、前腿交叉 |
| C13 | `hurt` | 1 | 受击后仰，头朝左（被打退的方向） |
| C14 | `down` | 2 | 倒地 + 爬起 |
| C15 | `win` | 1 | 胜利，坐姿翘头、尾巴摇起 |
| C16 | `lose` | 1 | 失败，趴地垂耳 |
